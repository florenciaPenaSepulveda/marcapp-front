# marcapp-front

App móvil/web de Marcapp para control de asistencia.

## Tecnologías

- React Native / Expo
- TypeScript

## Estructura

```
📄 App.tsx
📄 Router.tsx
📄 app.json
📁 assets
📄 babel.config.js
📄 package-lock.json
📄 package.json
📁 src
📄 tsconfig.json
```

## Cómo ejecutarlo

```bash
npm install
npm start
```

## Variables de entorno

Copia `.env.example` a `.env` y completa los valores (el `.env` real no se versiona):

- `EXPO_PUBLIC_MS_USER_URL`
